# Contributing

Taph is currently a language-design preview. Open an issue with the problem, proposed semantics, examples and alternatives, then submit a focused specification change. Changes need matching positive and negative conformance examples before implementation.

Use the milestones in order. Native-code performance claims require reproducible measurements under docs/TESTING.md. Keep unsafe runtime or LLVM integration code small, documented and covered by native checks. Do not introduce secrets, vendored credentials or generated build output.

Contributions are submitted under Apache-2.0. Preserve attribution and dependency notices.
